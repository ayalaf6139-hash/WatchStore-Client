# WatchStore Client

לקוח React מינימלי שמדגים את [WatchStore API](../WatchStore) מקצה לקצה.

## הרצה

```bash
npm install
npm run dev
```

הלקוח עולה ב-http://localhost:5173 ומדבר עם השרת ב-`http://localhost:5140/api`. אפשר לשנות את הכתובת דרך `VITE_API_URL` בקובץ `.env` (ראו `.env.example`). השרת צריך לרוץ עם `dotnet run --project WatchStore.API --launch-profile http`.

## מסכים

1. **התחברות / הרשמה:** ה-JWT נשמר ב-localStorage ונשלח ב-`Authorization: Bearer` בכל בקשה.
2. **קטלוג:** רשימת שעונים עם מחיר, מלאי, חיפוש, מיון ו-pagination שמתבצע בשרת.
3. **הזמנה:** בחירת כמות וביצוע `POST /api/orders`.
4. **התנגשות (409):** כשהמלאי נתפס על ידי חנות אחרת מוצגת ההודעה "המלאי של המוצר כבר נתפס על ידי משתמש אחר. אנא נסה שוב.", והרשימה מתרעננת.

## הדגמת 409

1. פותחים שני חלונות דפדפן: אחד רגיל ואחד בגלישה בסתר, ומתחברים בהם כ-`store1` וכ-`store2` (סיסמה `Store123!`).
2. בשניהם פותחים את חלון ההזמנה של ה-Rolex Submariner (יחידה אחת במלאי).
3. מזמינים בחלון הראשון: ההזמנה מצליחה.
4. מזמינים בחלון השני: מופיעה הודעת ה-409.
